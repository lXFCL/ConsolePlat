# Triage Labels

工程技能使用五种标准分类角色。下表定义这些角色在本仓库 Issue Tracker 中对应的标签。

| 技能中的标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由自动化 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或处理 |
| `wontfix` | `wontfix` | 决定不处理 |

当技能提到某个分类角色时，使用表中对应的仓库标签。若仓库以后调整标签名称，只修改第二列。
