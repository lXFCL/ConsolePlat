# ConsolePlat 页内教程设计

## 结论

ConsolePlat 内置教程采用“每页右上角问号按钮 + 高亮式页内引导”方案。用户在任意主页面点击右上角 `?` 后，软件启动当前页面对应教程，用遮罩、高亮区域和步骤说明卡片引导用户理解页面功能。

第一版只覆盖 ConsolePlat 软件内部页面，不自动点击真实业务按钮，不执行提交、上传、发货、修改库存、修改地址、开通 JIT 等外部状态变更动作。

## 目标

- 让用户在当前页面内直接找到教程入口，不增加左侧导航负担。
- 教程按页面上下文启动，避免用户从单独帮助页再反查当前功能。
- 用高亮和步骤说明解释页面关键区域，降低纯文字教程的理解成本。
- 教程内容可维护，后续页面调整时能集中更新步骤数据。
- 保留安全边界说明，避免用户误以为教程会替他们执行真实平台动作。

## 入口与交互

主窗口顶部右侧在现有状态胶囊旁增加一个圆形 `?` 按钮。

点击 `?` 后：

1. 获取当前激活页面 key，例如 `monitor`、`publish`、`local_image`、`ai_edit`、`putaway`、`apply`、`settings`。
2. 根据页面 key 查找教程步骤。
3. 如果存在教程，显示页内教程遮罩。
4. 如果不存在教程，显示轻量提示：“当前页面暂未配置教程”。

教程遮罩包含：

- 半透明背景，用于聚焦当前步骤。
- 高亮目标区域，用于指出当前讲解位置。
- 说明卡片，包含步骤序号、标题、说明、上一步、下一步、结束。

第一版不做首次启动强制弹窗，不做录屏，不做真实页面操作演示。

## 页面覆盖范围

第一版为当前主导航页面都预留教程配置：

- `monitor`：实时监控、刷新间隔、立即刷新、待处理列表、触发记录、安全只读边界。
- `publish`：产品任务、监控交接信息、发布前确认、同步到上架的入口。
- `local_image`：店铺、风格、数量、货号、任务日志、输出目录。
- `ai_edit`：输入图片、提示词/API Key、任务队列、失败清单、结果预览。
- `putaway`：PutawayAiRobot 嵌入区、投放目录、导入准备、失败提示。
- `apply`：ApplyGoods 嵌入区、合规/申请后置流程、人工确认点。
- `settings`：项目路径、浏览器 CDP、刷新间隔、主题、更新检查和敏感信息存储提示。

实际步骤文案以当前页面可见控件为准。若某些页面仍是半集成状态，教程需明确写出“当前为集成入口/预留能力”，不能把未完成流程描述成已可自动执行。

## 数据结构

教程内容使用结构化数据集中维护，建议新增 `consoleplat/ui/tutorial_data.py`。

每个步骤至少包含：

- `page_key`：所属页面。
- `target`：目标控件对象名或逻辑锚点。
- `title`：步骤标题。
- `body`：步骤说明。
- `safety_note`：可选安全提示。
- `screenshot`：可选截图资源路径。

目标控件优先通过稳定 `objectName` 查找。对于无法直接绑定控件的区域，使用页面级锚点或退化到居中说明卡片。

## 组件设计

建议新增两个 UI 组件：

- `TutorialButton`：主窗口右上角问号按钮，负责触发当前页面教程。
- `TutorialOverlay`：页内遮罩组件，负责步骤显示、目标区域高亮、按钮切换和结束。

`MainWindow` 负责：

- 放置问号按钮。
- 在按钮点击时读取当前页面 key。
- 调用教程覆盖层显示当前页步骤。

页面类负责：

- 为关键区域设置稳定 `objectName`。
- 不直接管理教程流程。

## 截图策略

用户希望教程内使用软件截图。第一版采用本地截图资产：

- 新增 `assets/images/tutorial/` 保存教程截图。
- 增加脚本或测试辅助逻辑，启动 PyQt 页面后截取主要页面静态图。
- 截图用于教程卡片中的缩略参考或后续教程目录，不作为高亮定位的唯一依据。

截图不包含账号、Cookie、API Key、真实订单号、真实库存或其他敏感信息。若页面中存在输入框或业务数据，截图前使用测试配置或空状态。

## 错误处理

- 当前页无教程步骤：显示友好提示，不报错。
- 步骤目标控件找不到：显示该步骤说明，但不画目标高亮，并记录开发日志。
- 页面切换时教程仍打开：自动结束当前教程，避免遮罩覆盖到错误页面。
- 窗口尺寸变化：重新计算目标控件位置。

## 测试与验证

需要补充或更新测试：

- 主窗口存在教程按钮。
- 点击教程按钮能为当前页打开 `TutorialOverlay`。
- 教程步骤支持下一步、上一步和结束。
- 无步骤页面显示友好提示。
- 关键页面教程数据没有缺失标题和说明。

验证命令：

```powershell
python -m py_compile main.py consoleplat\ui\main_window.py consoleplat\ui\theme.py
python -m pytest tests/test_main_window_ui.py tests/test_components.py -q
```

若实现过程中新增截图脚本，再补充对应脚本的静态校验或小范围运行验证。

## 风险

- 现有页面部分控件缺少稳定 `objectName`，需要少量补充，否则高亮定位会脆弱。
- 页面懒加载后才存在控件，教程启动时必须确保当前页已构建。
- 内置截图需要避免包含真实店铺或账号数据。
- 后续页面 UI 调整后，教程步骤和截图需要同步更新。

## 非目标

- 不在第一版加入首次启动强制教学弹窗。
- 不做视频教程或录屏播放。
- 不让教程自动点击真实业务按钮。
- 不把教程做成独立左侧导航页。
