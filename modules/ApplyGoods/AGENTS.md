## 回答与协作风格

- 回答问题时避免过分夸赞，优先保证准确性。
- 对用户判断和自身判断都保持复核态度；如果证据不足，主动说明不确定点。
- 输出尽量结构化，先给结论，再给关键依据和下一步。
- 遇到会改变页面状态、复制剪贴板、批量提交、删除、上传、发布等动作时，先确认动作范围是否符合用户当前指令。

## 项目目标

本项目用于自动化完成 Temu Agent Seller 的“申请商品”相关流程。

当前阶段：

1. 先用 Chrome 扩展验证页面动作和选择器。
2. 验证稳定后，迁移到 Playwright 实现。
3. 最终效果和 `E:\1PythonProject\SendGoods` 项目类似，使用本地桌面工具或脚本连接/启动浏览器完成流程。

已验证的第一段流程：

1. 打开 `https://agentseller.temu.com/goods/list`。
2. 将分页从每页 20 条切换为每页 50 条。
3. 全选当前页商品。
4. 读取或复制当前页商品的 SKC ID。
5. 后续步骤再按用户指令逐步补齐，并最终串联。

## 运行环境

- 优先使用 conda 里的 `flask` 环境。
- 运行 Python 相关命令时默认使用：

```powershell
conda run -n flask python <script.py>
```

- 安装或检查依赖时也优先在 `flask` 环境内完成，例如：

```powershell
conda run -n flask python -m pip show playwright
conda run -n flask python -m playwright install chromium
```

- `flask` 在本项目中只是 conda 环境名，不代表本项目一定是 Flask Web 项目。

## 技术方向

### Playwright

- 后续主实现使用 Python Playwright。
- 优先连接已有 Chrome 调试端口，保留用户登录态；如果无法连接，再启动独立浏览器配置目录。
- 可参考 `SendGoods` 的浏览器管理方式：
  - 优先连接 `http://127.0.0.1:9222`
  - 失败后启动持久化浏览器上下文
  - 使用项目内 `.browser-profile` 保存登录态

建议目标结构：

```text
ApplyGoods/
  main.py
  temu_goods.py
  browser_session.py
  models.py
  app_paths.py
  requirements.txt
  chrome-extension/
  README.md
  AGENTS.md
```

### Chrome 扩展

- `chrome-extension/` 是当前验证层，用来快速确认页面 DOM、按钮文案、交互顺序。
- 不要把扩展代码当作最终主实现；Playwright 版本才是后续主线。
- 扩展里验证过的页面流程和文案定位可以迁移到 Playwright。

- 页面文本中有 `全部 520`、`在售中 397`、`未发布到站点 88` 等状态统计。
- 批量操作区有：
  - `新建商品`
  - `挑选机会商品发布`
  - `下载查询结果520`
  - `批量删除`
  - `更多`
- 表格表头包含：
  - `商品信息`
  - `SKU ID`
  - `商品规格`
  - `操作`
- 商品信息中包含：
  - `SPU ID：`
  - `SKC ID：`
  - `货号：`

已验证可行操作：

- 分页输入框可从 `20` 切换到 `50`。
- 表头全选框可通过坐标或 DOM 定位点击。
- 全选成功后，`批量删除` 会从禁用变为可用。
- 可直接从 DOM 文本中用正则提取当前可见商品的 SKC ID：

```python
r"SKC ID[:：]\s*(\d+)"
```

注意：

- `更多` 按钮在内置浏览器测试中可以命中，但没有通过普通点击、坐标点击、Enter、双击稳定展开菜单。
- Playwright 实现时应同时准备两条路径：
  - 优先尝试页面原生菜单：`更多 > 批量复制ID > SKC ID`
  - 备用方案：直接从 DOM 提取当前页 SKC ID，并写入程序结果或剪贴板

## 编码规范

- 默认使用 Python 3，保持类型标注。
- 优先写小而清晰的函数，不要过早抽象。
- 浏览器选择器要集中管理，方便页面变化后维护。
- 对页面动作加明确日志，例如：
  - 正在打开商品列表
  - 当前分页为 20，准备切换到 50
  - 已全选当前页商品
  - 已提取 SKC ID：N 个
- 对失败原因给出可操作提示，不要只抛原始异常。

## 数据与安全

- 不要提交 `.browser-profile/`、`downloads/`、`outputs/`、`__pycache__/` 等运行时目录。
- 不要在代码或文档中保存账号、密码、Cookie、Token。
- 自动化过程中不要未经确认执行删除、发布、提交申请、上传文件等有外部影响的动作。
- 读取 DOM、切换分页、全选、复制 ID 属于当前已授权验证范围。
