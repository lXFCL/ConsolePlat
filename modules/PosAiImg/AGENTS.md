# PosAiImg 项目 Agent 指南

## 沟通原则

- 使用中文，结构化说明。
- 避免过分夸赞；优先保证准确性。
- 信息不足、路径冲突、文件缺失、视觉结果不确定时，要明确说明“不确定/需要验证”。
- 如果用户判断和当前文件证据冲突，先列证据，再给建议。
- 对会影响原图、批量结果、模型文件、投放目录或运行环境的操作，执行前先说明风险。
- 回复中给用户结果位置时，必须使用可点击的 Markdown 文件/目录链接，不要只写纯文本路径。链接目标使用绝对路径，例如 `[批次目录](E:/1PythonProject/PosAiImg/图库/BO/2026/6月/xxx)`。

## 项目目标

本项目围绕服装图片做低成本批量出图流水线：

1. 生成或准备印花图。
2. 将印花图处理成透明底素材。
3. 将透明底印花批量贴到干净 T 恤主图上。
4. 生成产品图和 xlsx 表格。
5. 正式批次同步到 `E:\1PythonProject\PutawayAiRobot\data` 投放目录。

## 新图库目录规则

新流程不再把 `印花图/` 作为正式目录使用。`印花图/` 只视为历史兼容目录或旧脚本临时输入目录。

新批次的印花素材统一放在 `图库/` 下，先按店铺分，再按年份和月份分，再按批次分。

标准结构：

```text
图库/
  BO/
    2026/
      6月/
        xx风格_BO-起始-BO-结束_日期/
          测试/
          最终透明底/
  SZW/
    2026/
      6月/
        xx风格_SZW-起始-SZW-结束_日期/
          测试/
          最终透明底/
```

含义：

- `测试/`：放本地模型原生生成图、测试图、候选图、临时预览图等，不作为最终贴图素材。
- `最终透明底/`：只放最终可用于贴图的透明 PNG，文件名必须按货号命名，例如 `BO-1421.png`。
- 同一批次如果有多轮测试，仍放在该批次 `测试/` 内，可用子目录或文件名区分。
- 正式透明底文件不要混入 `_overview.jpg`、调试图、raw 图或非货号图片。

## 批量贴图结果目录规则

批量贴图结果也按店铺、年份、月份、批次分层。

标准结构：

```text
批量贴图结果/
  BO/
    2026/
      6月/
        xx风格_BO-起始-BO-结束_日期/
          测试/
          最终产品图/
  SZW/
    2026/
      6月/
        xx风格_SZW-起始-SZW-结束_日期/
          测试/
          最终产品图/
```

含义：

- `测试/`：放贴图测试总览、抽样预览、候选贴图，不作为最终投放图。
- `最终产品图/`：只放最终上架产品图，文件名格式为 `货号_产品标题.png`。
- `_overview.jpg` 放在 `测试/`，不要放进 `最终产品图/`；最终产品图目录只保留可投放产品图。

## 主要脚本

- `tools/tshirt_print_tool.py`
  - Tkinter 可视化贴图工具。
  - 支持批量把印花合成到模特图。
  - 关键参数：`center_x`、`center_y`、`width`、`opacity`、`rotation`、`shadow_strength`、`wave_strength`。

- `tools/remove_print_bg.py`
  - 将接近白色的印花背景转为透明。
  - 旧默认目录仍可能指向 `印花图/` 和 `印花图_透明底/`；新批次应显式传入 `图库/.../测试` 和 `图库/.../最终透明底`。

- `tools/comfy_print_batch.py`
  - 通过本地 ComfyUI API 批量生成印花图。
  - 默认连接 `http://127.0.0.1:8188`。
  - 使用前注意检查路径变量是否仍是旧目录或有编码错乱。

- `tools/generate_bo_painterly_master_batch.py`
  - BO/SZW 仿油彩名画风格竖版印花批次脚本。
  - 已使用新目录结构：`图库/店铺/年份/月/批次/测试`、`最终透明底`，以及 `批量贴图结果/店铺/年份/月/批次/测试`、`最终产品图`。

- `tools/remove_model_prints.py`
  - 从模特图中自动识别并修补胸前印花区域。
  - 结果质量依赖图片构图、衣服颜色、原印花复杂度，不能假设每张都完美。

## 常用运行方式

从项目根目录运行。

```bat
conda run -n posai-img python tools\tshirt_print_tool.py
```

```bat
conda run -n posai-img python tools\tshirt_print_tool.py --batch
```

```bat
conda run -n posai-img python tools\remove_print_bg.py
```

启动 ComfyUI：

```bat
cd ComfyUI
conda run -n posai-comfy python main.py --listen 127.0.0.1 --port 8188
```

也可以使用根目录下的批处理：

- `启动贴图工具.bat`
- `启动ComfyUI.bat`
- `批量生成印花.bat`
- `印花去白底.bat`
- `一键生成贴图.bat`

## 修改原则

1. 优先改 `tools/` 和根目录项目脚本，不要无关改动 `ComfyUI/`。
2. 处理中文路径时使用 `pathlib.Path`，避免手写路径拼接。
3. 图像读写优先保持 EXIF 方向正确，可参考 `ImageOps.exif_transpose`。
4. 批量任务必须清楚区分输入目录、测试目录、最终目录，避免覆盖原始素材。
5. 对图片算法参数保持保守，尤其是去白底阈值、印花遮罩范围和模特修补区域。
6. 新增功能要保留命令行可用性，尽量不要只做 GUI 入口。
7. 需要长时间运行 ComfyUI 或批量出图时，先说明会启动本地服务或占用 GPU。
8. 不要删除生成结果或素材目录，除非用户明确要求并确认目标路径。
9. 贴花位置必须限制在 T 恤胸口正中心区域，不能超过领口，也不能延伸到 T 恤底部；除非任务明确要求右胸或左胸小标设计，否则不要把印花贴到偏左、偏右、过高或过低的位置。

## BO/SZW 正式批次流程

当用户要求“全流程”“正式批量”“从当前货号继续”“做一批 BO/SZW 产品图”时：

1. 先读取 `BO_PROGRESS.md` 或对应进度记录。
2. 如果用户显式指定起始货号，以用户指定为准，但要说明是否与进度记录一致。
3. 批次范围按 `起始货号 + 计划数量 - 1` 计算。
4. 生成或整理印花时：
   - 测试图、原生图放 `图库/店铺/年份/月/批次/测试`。
   - 最终透明底放 `图库/店铺/年份/月/批次/最终透明底`。
   - 最终透明底必须按货号命名。
5. 贴图时：
   - 测试预览放 `批量贴图结果/店铺/年份/月/批次/测试`。
   - 最终产品图放 `批量贴图结果/店铺/年份/月/批次/最终产品图`。
6. 生成 xlsx 到 `衣物对应的xlsx/BO` 或 `衣物对应的xlsx/SZW`。
7. 同步投放：
   - 清空 `E:\1PythonProject\PutawayAiRobot\data\pic\1` 中旧图片。
   - 将本批次最终产品图复制到该目录。
   - 将本批次 xlsx 复制到 `E:\1PythonProject\PutawayAiRobot\data`。
8. 更新进度文件。

## 产品标题规则

BO 批量标题不要过短，也不要写性别、人群、情侣装等词。

推荐标题格式：

```text
夏季{颜色}{风格}{图案词}印花T恤 {卖点短语}
```

卖点短语可从以下选择或轻微变化：

- 圆领短袖 透气微弹针织上衣 日常休闲百搭
- 圆领短袖 透气舒适针织上衣 户外休闲日常百搭
- 圆领短袖 轻薄透气针织上衣 休闲通勤日常百搭
- 圆领短袖 柔软透气针织上衣 夏季日常百搭

Excel 的产品标题必须与产品图文件名中的标题一致。

## 必做校验

正式批次完成前必须校验：

- 最终透明底数量等于计划数量。
- 最终产品图数量等于计划数量。
- 文件名中的货号连续且无重复。
- xlsx 行数等于计划数量 + 1。
- xlsx 表头为 `店铺名称、产品分类、产品标题、产品序列号、颜色`。
- xlsx 首条和末条货号符合本批范围。
- 店铺名称正确。
- 投放目录图片数量、货号范围、无缺号，xlsx 文件存在。
- 打开 `_overview.jpg` 或抽样产品图做视觉检查，并说明发现的问题。

## 已知注意点

- 历史文件和部分旧脚本可能有编码错乱。引用旧说明前，应从脚本或实际目录交叉验证。
- 一些脚本或批处理依赖 Conda 环境：`posai-img` 和 `posai-comfy`。
- 图片结果属于视觉质量问题时，不要只凭文件生成成功下结论；应查看样图或总览图。
- 默认贴图参数适合正面 T 恤胸前区域。侧身、大透视、衣物遮挡、复杂褶皱需要单独调参或升级算法。
