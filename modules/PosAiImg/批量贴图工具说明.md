# 批量 T 恤贴图工具说明

这是第一版本地低成本流程工具，用来把印花图批量贴到干净的 T 恤模特图上。

## 目录

- 干净模特图：`E:\1PythonProject\PosAiImg\去印花结果`
- 印花图：`E:\1PythonProject\PosAiImg\印花图`
- 输出结果：`E:\1PythonProject\PosAiImg\批量贴图结果`

## 启动

双击项目根目录里的 `启动贴图工具.bat`。

也可以在终端运行：

```bat
conda run -n posai-img python tools\tshirt_print_tool.py
```

## 使用方式

1. 把 PNG/JPG/WEBP 印花图放进 `印花图` 文件夹。
2. 打开工具，先看右侧预览。
3. 调整 `Center X`、`Center Y`、`Print width`、`Opacity` 等参数。
4. 点击 `Batch export`，工具会把每张模特图和每张印花图组合导出。

## 命令行批量

```bat
conda run -n posai-img python tools\tshirt_print_tool.py --batch
```

生成示例印花并批量导出：

```bat
conda run -n posai-img python tools\tshirt_print_tool.py --make-samples --batch
```

## 说明

第一版主要解决低成本批量出图：位置、大小、透明度、阴影融合和轻微褶皱波形都可以调。它不是 AI 精修，所以极端褶皱、侧身大透视、衣服遮挡等场景还需要后续升级。

## 本地 AI 生成印花

已经配置了 ComfyUI + SDXL Base，本地生成印花不用按张付费。

1. 双击 `启动ComfyUI.bat`，等窗口显示本地服务启动。
2. 修改 `印花提示词.txt`，一行一个印花主题。
3. 双击 `批量生成印花.bat`。
4. 生成图会自动保存到 `印花图` 文件夹。
5. 可选：双击 `印花去白底.bat`，把白底转成透明底，输出到 `印花图_透明底`。
6. 再双击 `启动贴图工具.bat`，把生成好的印花批量贴到模特图上。

当前模型文件是 `sd_xl_base_1.0.safetensors`，约 6.9GB，低于 20GB。
